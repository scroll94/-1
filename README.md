# Онлайн-школа

Веб-платформа для школы: уроки с видео, домашние задания, проверка и оценки.

**Роли:**
- **Администратор** — создаёт пользователей (учеников, учителей), классы, назначает учителей, сбрасывает пароли.
- **Учитель** — ведёт свои классы: курсы, уроки, загрузка видео и файлов, домашние задания, проверка, оценки, комментарии, журнал.
- **Ученик** — смотрит уроки и видео, сдаёт ДЗ (текст, файл, фото), видит оценки и комментарии учителя.

**Технологии:** Next.js 15 + TypeScript + Tailwind CSS, Supabase (PostgreSQL, вход, хранилище файлов), хостинг Vercel.

## Запуск (один раз)

### 1. Supabase — база данных

1. Откройте проект в [supabase.com](https://supabase.com) → слева **SQL Editor** → **New query**.
2. Скопируйте **весь** файл [`supabase/schema.sql`](supabase/schema.sql), вставьте и нажмите **Run**.
   Должно появиться `Success. No rows returned`.
3. **Authentication → Sign In / Providers** (или **Settings**): выключите **Allow new users to sign up**,
   чтобы аккаунты создавал только администратор.
4. **Project Settings → API Keys** — понадобятся три значения:
   - **Project URL** (`https://xxxx.supabase.co`)
   - **publishable / anon** ключ (публичный)
   - **secret / service_role** ключ (**секретный**: никому не показывать и не присылать в чат)

### 2. Vercel — сайт

1. [vercel.com/new](https://vercel.com/new) → **Import** репозитория.
2. Перед **Deploy** откройте **Environment Variables** и добавьте:

   | Name | Value |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | publishable / anon ключ |
   | `SUPABASE_SERVICE_ROLE_KEY` | secret / service_role ключ |
   | `NEXT_PUBLIC_SITE_NAME` | название школы (необязательно) |

3. **Deploy**. Через 1–2 минуты сайт откроется по адресу `…vercel.app`.

### 3. Первый администратор

Откройте `https://ваш-сайт.vercel.app/setup` и создайте главного администратора.
Страница работает только один раз — пока в системе нет ни одного админа.

### 4. Наполнение

1. **Пользователи** → создайте учителей и учеников (логин можно без email, например `ivanov.a`).
2. **Управление классами** → создайте класс, назначьте учителя, добавьте учеников.
3. Учитель открывает **Мои классы** → класс → создаёт курс → уроки → загружает видео/файлы → создаёт ДЗ.
4. Ученик сдаёт работу → учитель на главной видит «Ждут проверки» → ставит оценку или отправляет на доработку.

## Пароли и безопасность

- Пароли хранятся только в зашифрованном виде (хэш) — их не видит никто, даже админ. Админ может задать новый пароль.
- Права доступа проверяются на уровне базы данных (Row Level Security):
  ученик видит только свои классы и свои работы, учитель — только свои классы, поставить оценку себе ученик не может.
- Секретный ключ `SUPABASE_SERVICE_ROLE_KEY` используется только на сервере.

## Ограничения бесплатного тарифа

- Supabase Free: база 500 МБ, файлы 1 ГБ, **один файл до 50 МБ**. Длинные видео лучше сжимать,
  выкладывать на YouTube «по ссылке» (вкладка «Добавить ссылку» в уроке) или перейти на тариф Pro.
- Бесплатный проект Supabase засыпает после недели без активности — его можно разбудить в панели.
- Vercel Hobby — только для некоммерческого использования.

## Локальная разработка

```bash
cp .env.example .env.local   # заполнить значения
npm install
npm run dev                  # http://localhost:3000
```

## Структура

```
supabase/schema.sql          таблицы, права доступа, хранилище
src/middleware.ts            проверка входа
src/lib/                     клиенты Supabase, утилиты, загрузка файлов
src/app/login, setup         вход и первичная настройка
src/app/(app)/               страницы после входа
  page.tsx                   главная (ДЗ ученика / работы на проверку)
  admin/users, admin/classes админка
  classes/[id]               класс: курсы, задания, журнал
  courses/[id], lessons/[id] курсы и уроки с видео
  assignments/[id]           задание: сдача и проверка
  grades                     оценки ученика
  actions.ts                 серверные действия
src/components/              формы загрузки, кнопки, бейджи
```
