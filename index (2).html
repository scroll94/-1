Научись создавать магию с помощью кода! Питон — это язык программирования, которым пользуются учёные, игроделы и изобретатели.

👋
Урок 1 Привет, мир!

Самая первая программа, которую пишут все программисты — это «Привет, мир!». Питон умеет показывать текст на экране с помощью команды print().

💻 Код 
print("Привет, мир!")
print("Меня зовут Питон 🐍")
print("Я умею считать: 2 + 2 =", 2 + 2)
📺 Результат

Привет, мир!
Меня зовут Питон 🐍
Я умею считать: 2 + 2 = 4

💡

Запомни! Текст всегда пишется в кавычках "вот так". Без кавычек Питон не поймёт, что это слова, а не команды.

Урок 2 Переменные — коробки для данных

Представь, что переменная — это коробка с наклейкой. На наклейке написано имя коробки, а внутри лежат данные. Ты можешь положить туда что угодно!

💻 Код 
имя = "Алиса"          # текст
возраст = 9             # число
рост = 135.5          # дробное число
любит_кошек = True    # да/нет

print("Привет, меня зовут", имя)
print("Мне", возраст, "лет")
print("Через год мне будет", возраст + 1)
📺 Результат

Привет, меня зовут Алиса
Мне 9 лет
Через год мне будет 10

🎁

В Питоне есть 4 вида данных: текст (str), целые числа (int), дробные (float) и правда/ложь (bool — True/False).

Урок 3 Питон — умный калькулятор

Питон умеет считать лучше любого калькулятора! Посмотри на все операции, которые он знает:

💻 Код 
print(10 + 5)    # Сложение → 15
print(10 - 3)    # Вычитание → 7
print(4 * 6)     # Умножение → 24
print(15 / 2)    # Деление → 7.5
print(15 // 2)   # Деление без остатка → 7
print(15 % 2)    # Остаток от деления → 1
print(2 ** 8)    # Степень → 256

# Считаем площадь комнаты!
длина = 5
ширина = 4
площадь = длина * ширина
print("Площадь комнаты:", площадь, "м²")
📺 Результат

15 · 7 · 24 · 7.5 · 7 · 1 · 256
Площадь комнаты: 20 м²

Урок 4 Если... то... иначе!

Питон умеет принимать решения! Команда if проверяет условие и выполняет разный код в зависимости от ответа.

💻 Код 
возраст = 9

if возраст >= 18:
    print("Ты взрослый!")
elif возраст >= 13:
    print("Ты подросток")
else:
    print("Ты ребёнок 🧒")

# Угадай число!
секретное = 7
догадка = 5

if догадка == секретное:
    print("🎉 Угадал!")
elif догадка < секретное:
    print("📈 Больше!")
else:
    print("📉 Меньше!")
📺 Результат

Ты ребёнок 🧒
📈 Больше!

⚖️

Знаки сравнения: == равно, != не равно, > больше, < меньше, >= больше или равно, <= меньше или равно. Не путай = (присвоить) и == (сравнить)!

Урок 5 Циклы — делай много раз!

Цикл — это суперсила программиста! Вместо того чтобы писать одно и то же 100 раз, просто скажи Питону: «повтори это!»

💻 Код — цикл for 
# Считаем от 1 до 5
for i in range(1, 6):
    print("Шаг номер", i)

# Таблица умножения на 3
for число in range(1, 11):
    print("3 ×", число, "=", 3 * число)

# Рисуем лесенку звёздочками
for i in range(1, 6):
    print("⭐" * i)
📺 Результат (лесенка)

⭐
⭐⭐
⭐⭐⭐
⭐⭐⭐⭐
⭐⭐⭐⭐⭐

💻 Код — цикл while 
# Считаем, пока не дойдём до 5
счёт = 0
while счёт < 5:
    print("Счёт:", счёт)
    счёт = счёт + 1
print("Готово! 🚀")
⚠️

Осторожно! В цикле while всегда нужно изменять переменную, иначе цикл никогда не остановится — это называется «бесконечный цикл»!

Урок 6 Функции — твои суперсилы

Функция — это мини-программа внутри программы. Придумай её один раз — и используй хоть тысячу раз! Создаётся с помощью слова def.

💻 Код 
# Создаём функцию
def поздороваться(имя):
    print("Привет,!", имя, "👋")

# Используем её
поздороваться("Артём")
поздороваться("Маша")
поздороваться("Дракон")

# Функция с возвратом результата
def сложить(а, б):
    результат = а + б
    return результат

сумма = сложить(15, 27)
print("15 + 27 =", сумма)
📺 Результат

Привет! Артём 👋
Привет! Маша 👋
Привет! Дракон 👋
15 + 27 = 42
